# 测试计划（交互与渲染专项）

目标：把「能跑」变成「好看且顺手」。用例按功能域分组，带编号、操作、预期；⭐ 为本轮必须跑通的真实模型场景。

## A. 对话与渲染（R）

| 编号 | 用例 | 操作 | 预期 |
| --- | --- | --- | --- |
| R1 ⭐ | 基础问候 | 发「你好」 | 回复出现；无过程行；答案左对齐铺满；无横向溢出 |
| R2 ⭐ | 行内代码 | 回复里含 `C:\path` | 渲染为 code 元素，正文无裸反引号 |
| R3 ⭐ | 加粗/斜体/删除线 | `**粗** *斜* ~~删~~` | 分别渲染 strong/em/del |
| R4 ⭐ | 无序/有序列表 | 两段列表 | ul/ol 与 li 数量正确，缩进正常 |
| R5 ⭐ | 围栏代码块 | 三行 JS | pre>code 保留换行；块可横向滚动不撑破布局 |
| R6 ⭐ | 表格 | 3×3 表格 | table/th/td 渲染，窄窗口下不溢出 |
| R7 ⭐ | 引用与分隔线 | > 引用 + --- | blockquote/hr 出现 |
| R8 | 链接 | `[x](https://…)` | a 元素，点击走系统浏览器（不跳应用） |
| R9 | 长篇中文 | 2000 字中文 | 正常换行，行高一致，无横向滚动 |
| R10 | 超长单词/路径 | 300 字符无空格 | 强制断行，不撑破面板 |
| R11 | 流式中 | 慢速 SSE | 光标闪烁；内容增长；贴底处自动跟随 |
| R12 | 向上滚动 | 流式中上滚 | 不强制回底；出现「回到最新」 |
| R13 | 空回复 | 模型只回空串 | 不渲染空气泡；状态行显示已完成 |
| R14 | 多轮渲染 | 3 轮问答 | 每轮独立；旧轮折叠；答案可见 |
| R15 | 错误回复 | 401/网络错 | 显示可读错误；不折叠错误；可重试 |

## 执行策略

1. 每轮先跑自动化 UI 套件（1–25 组，离线假端点），保证回归。
2. 真实模型场景（⭐）每次 6 个场景 × 3 轮，记录耗时、截图、断言：Markdown 元素、无横向溢出、过程折叠、答案可见。
3. 失败即修，修完重跑三轮；报告记录通过率与截图。
